**Epic:** #210 — EPIC 12 — WhatsApp Agent (Evolution) + NLP
**Prioridade:** P1

### Objetivo
Implementar a camada de NLP básica para que o agente WhatsApp consiga identificar a intenção do usuário e extrair dados relevantes das mensagens recebidas, permitindo que as próximas stories executem ações reais no sistema Finlly.

### Escopo

**Inclui:**
- Identificação de intents a partir da mensagem do usuário
- Extração de entidades relevantes (valor, descrição, categoria, data)
- MVP com regex + parsing simples
- Estrutura modular preparada para evolução futura (classificador, LLM)
- Integração com o fluxo do webhook já existente (Story 12.1)
- Logging da intent detectada e dados extraídos
- Resposta padrão para intent UNKNOWN

**Não inclui:**
- Execução de ações no sistema — Story 12.3
- Controle de sessão/autenticação — Story 12.5
- Uso de LLM ou IA avançada (fase futura)

### Estrutura de intents mínima

| Intent | Descrição |
|---|---|
| CREATE_EXPENSE | Registrar uma despesa |
| CREATE_INCOME | Registrar uma receita |
| GET_BALANCE | Consultar saldo |
| GET_STATEMENT | Consultar extrato/resumo |
| UNKNOWN | Mensagem não reconhecida |

### Exemplos de parsing

| Mensagem do usuário | Intent | Dados extraídos |
|---|---|---|
| "gastei 50 no almoço" | CREATE_EXPENSE | valor: 50, descrição: almoço |
| "recebi 2000 do cliente X" | CREATE_INCOME | valor: 2000, origem: cliente X |
| "quanto tenho em caixa?" | GET_BALANCE | — |
| "me mostra meus gastos da semana" | GET_STATEMENT | período: semana |
| "bom dia!" | UNKNOWN | — |

### Detalhes técnicos

Novo módulo: services/nlpService.js
Função: identificarIntent(texto) → { intent, params }

Integração com whatsappService.js:
mensagem recebida → processarMensagemRecebida() → nlpService.identificarIntent(texto) → { intent, params } → log + resposta ao usuário

Resposta para UNKNOWN: "Não entendi sua mensagem. Você pode tentar: 'gastei 50 no almoço', 'recebi 2000', 'quanto tenho em caixa?""
